**AIGateway** unifies providers, models, and quotas for popular AI tools so you can spend fewer tokens and switch cheaper vendors more easily.

- **Works with:** ChatGPT / Codex · Claude Code · OpenClaw · Harness · any OpenAI-compatible client  
- **Default gateway:** `http://127.0.0.1:18080/v1`
