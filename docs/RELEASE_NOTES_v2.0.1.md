## 简体中文

### 这是什么

**AIGateway v2.0.1** 是一次正式发布，用来把当前的 v2 网关、SQLite 状态、模型组路由、应用接管和多语言文档一起打包成可下载版本。

### 这次发布包含

- 本地网关 `127.0.0.1:18080/v1`
- SQLite 主状态与迁移逻辑
- 虚拟模型组与 failover
- 厂家管理、模型管理、应用管理、统一入口、Token 统计
- 多语言界面与 GitHub Wiki 文档
- 适配 Codex / ChatGPT / Claude Code / OpenClaw / Harness 的工具接管逻辑

## English

### Overview

**AIGateway v2.0.1** is the first formal v2 release published from this workspace. It packages the current gateway, SQLite-backed state, model-group routing, app takeover flow, and multilingual docs into downloadable release assets.

### Included

- Local gateway at `127.0.0.1:18080/v1`
- SQLite-backed state and migration path
- Virtual model groups with failover
- Providers, models, apps, gateway, and usage views
- Multilingual UI and GitHub Wiki docs
- Tool takeover support for Codex / ChatGPT / Claude Code / OpenClaw / Harness
